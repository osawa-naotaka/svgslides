# 要件定義書 - SVGSlides

## 目的

本文書では、SVGSlides PHASE1のMVPの開発に必要な要件を定義します。
次のPHASEへのたたき台となるとともに、最低限の実動作が実現できるかを確認します。
PHASE1では、プレゼンテーション機能は有せず、サムネイルリスト表示機能とSVGテキスト表示機能（可能であれば編集機能）を持ちます。
 
## 概要

### 機能概要

SVGSlidesは、複数のSVGファイルをYAML形式のドキュメントで管理し、編集・プレゼンテーション表示を行うデスクトップアプリケーションです。PHASE1では以下の機能を実装します：

- YAMLドキュメントの読み込み
- 参照されたSVGファイルのサムネイル一覧表示
- サムネイル選択によるSVGテキストの表示
- SVGテキストの編集とリアルタイムプレビュー（可能であれば）

### ペルソナと特性

ユーザーは開発者(lulliecat)1人とします。今後の開発の足掛かりとしてのみ使います。

- TypeScript/Electronの開発経験がある
- SVGフォーマットの基本的な理解がある
- コマンドライン操作やテキストエディタでの編集に慣れている
- YAMLフォーマットの読み書きができる

### 動作環境

- Windows 11 Pro x64環境で動作します。
- Node.js 18以上がインストールされている開発環境

### 前提条件

- ユーザーは事前にYAMLドキュメントを手動で作成している
- YAMLドキュメントには有効なSVGファイルへのパスが記述されている
- SVGファイルは有効なSVG形式である
- すべてのファイルはローカルファイルシステム上に存在する

### 制約条件

- PHASE1ではGUIによるドキュメント作成機能は実装しない
- YAMLファイルとSVGファイルのバリデーションは最低限とする
- エラーハンドリングは開発者が理解できる程度の簡易的なもの
- パフォーマンス最適化は後のフェーズで実施
- クロスプラットフォーム対応は考慮するが、動作確認はWindows 11のみ

## 機能要件

### FR-01: YAMLドキュメント読み込み機能
- 優先度: 必須
- 説明: 指定されたYAMLファイルを読み込み、SVGファイルへの参照リストを取得する
- 詳細:
  - ファイル選択ダイアログからYAMLファイルを選択できる
  - YAMLファイルのフォーマットは以下の通り：
    ```yaml
    slides:
      - path: "./slides/slide01.svg"
      - path: "./slides/slide02.svg"
      - path: "./slides/slide03.svg"
    ```
  - 相対パスはYAMLファイルからの相対パスとして解釈する
  - 読み込みエラー時はコンソールにエラーメッセージを出力する

### FR-02: サムネイルリスト表示機能
- 優先度: 必須
- 説明: YAMLで参照されているSVGファイルをサムネイル形式で一覧表示する
- 詳細:
  - 左カラムに縦方向のスクロール可能なリストとして表示
  - 各サムネイルはSVGを縮小表示したもの
  - サムネイルサイズは幅固定（例：200px）、高さはアスペクト比を維持
  - リストの順序はYAMLファイルの記述順に従う
  - ファイルが見つからない場合は「File Not Found」などのプレースホルダーを表示

### FR-03: サムネイル選択機能
- 優先度: 必須
- 説明: サムネイルをクリックして選択状態にする
- 詳細:
  - クリックされたサムネイルに視覚的な選択状態を表示（枠線の色を変える等）
  - 初期状態では最初のサムネイルが選択されている
  - 選択変更時に右カラムの表示内容が更新される

### FR-04: SVGテキスト表示機能
- 優先度: 必須
- 説明: 選択されたSVGファイルのテキスト内容を表示する
- 詳細:
  - 右カラムにSVGファイルの生テキストを表示
  - シンタックスハイライトがあることが望ましい（monaco-editorやCodeMirror使用を推奨）
  - 読み取り専用モードでも可（編集機能は次の要件で対応）

### FR-05: SVGテキスト編集機能
- 優先度: 推奨（可能であれば実装）
- 説明: 表示されているSVGテキストを編集し、変更を反映する
- 詳細:
  - 右カラムでSVGテキストを直接編集可能にする
  - 編集内容は即座にサムネイルに反映される（デバウンス処理推奨：300-500ms程度）
  - 編集内容はファイルに自動保存、または保存ボタンによる明示的な保存
  - 不正なSVGの場合でもクラッシュせず、エラー表示やデフォルト表示を行う

### FR-06: 2ペインレイアウト機能
- 優先度: 必須
- 説明: 左右2つのカラムに分割されたレイアウトを提供する
- 詳細:
  - 左カラム：サムネイルリスト表示エリア
  - 右カラム：SVGテキスト表示/編集エリア
  - 中央に境界バーを配置し、ドラッグで左右の幅を調整可能
  - 初期状態では左：右 = 3：7 程度の比率
  - 最小幅を設定し、カラムが完全に隠れないようにする（例：各200px以上）

### FR-07: アプリケーション起動機能
- 優先度: 必須
- 説明: Electronアプリケーションとして起動する
- 詳細:
  - ウィンドウサイズは初期値 1280x720程度
  - ウィンドウはリサイズ可能
  - タイトルバーに「SVGSlides」と表示

## 非機能要件

### NFR-01: パフォーマンス
- サムネイルの読み込みは1ファイルあたり500ms以内（目標値）
- SVG編集時のプレビュー更新は1秒以内（デバウンス後）
- 10ファイル程度の管理で動作が確認できること

### NFR-02: 保守性
- TypeScriptで記述し、型安全性を確保する
- 主要な関数にはコメントを記述する
- ディレクトリ構成は提案されたアーキテクチャに従う

### NFR-03: 可用性
- SVGファイル読み込みエラー時もアプリケーションがクラッシュしない
- 不正なYAMLファイルの場合はエラーメッセージを表示し、空のリストを表示

### NFR-04: セキュリティ
- ローカルファイルシステムへのアクセスのみ許可
- 外部ネットワークへの通信は行わない（PHASE1では不要）

## UI要件

### UI-01: 全体レイアウト
```
+------------------------------------------+
|  SVGSlides                     [_][□][X] |
+------------------------------------------+
|  [File] [Help]                           |
+------------------------------------------+
| サムネイル    |│|   SVGテキスト表示        |
| リスト        |│|   /編集エリア            |
|              |│|                         |
| [Thumb1]     |│|  <svg...>               |
| [Thumb2]     |│|    <rect.../>           |
| [Thumb3]     |│|    <text.../>           |
|   ...        |│|  </svg>                 |
|              |│|                         |
| (スクロール)  |│|  (エディタ)              |
+------------------------------------------+
```

### UI-02: カラーテーマ
- ダークモード・ライトモードは任意（開発者が好む方）
- サムネイル選択状態は明確に識別できる色（例：青枠、背景色変更）

### UI-03: メニューバー
- **File**
  - Open Document... (Ctrl+O) : YAMLファイルを開く
  - Exit (Alt+F4) : アプリケーション終了
- **Help**
  - About : バージョン情報表示

### UI-04: サムネイルリスト
- 各サムネイルの下にファイル名を表示
- ホバー時にツールチップで完全なパスを表示（任意）
- スクロールバーを表示

### UI-05: SVGエディタ
- 等幅フォント使用
- 行番号表示（推奨）
- シンタックスハイライト（推奨）
